# Security Policy

## Disclosure

If you find a security vulnerability in any smart contract or the protocol itself, **do not open a public issue**.

Contact: [@lekanay2005-coder](https://github.com/lekanay2005-coder) on GitHub with full details.

## Scope

In-scope for security review:

- `contracts/` — all Soroban smart contracts (registry, escrow, settlement, shared)
- `packages/sdk/src/` — client-side SDK logic
- `indexer/src/` — event indexer service

Out of scope:

- Frontend UI logic
- Documentation

## Audit Disclaimer

These contracts have **not been audited**. Use at your own risk. A formal audit is planned before mainnet deployment.

## Expected Response

Reports acknowledged within 72 hours. Critical issues patched within 7 days of confirmation.
